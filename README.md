## 📋 Project Description

**Personal Portfolio** is a responsive personal portfolio website built with HTML, CSS, Tailwind CSS, and JavaScript to showcase skills, projects, experience, and contact information.

The project focuses on using JavaScript to create interactive UI features such as theme switching, active navigation links, portfolio filtering, testimonials carousel, customization settings, and scroll-to-top functionality.

---

## ✨ Features

- 🌓 **Dark & Light Mode** - Switch between dark and light themes
- 🧭 **Active Navbar Link** - Automatically updates based on scroll position
- 📂 **Portfolio Tabs** - Filter projects by category using JavaScript
- 💬 **Testimonials Carousel** - Interactive customer testimonials slider
- ⚙️ **Customization Sidebar** - Customize website fonts and theme colors
- 🎨 **Theme Customization** - Change the website appearance dynamically
- ⬆️ **Scroll To Top** - Quickly return to the top of the page
- 📱 **Responsive Design** - Works across mobile, tablet, and desktop devices
- 🖥️ **Modern Portfolio Layout** - Sections for skills, projects, experience, testimonials, and contact
